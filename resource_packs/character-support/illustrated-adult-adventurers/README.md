# Illustrated adult adventurer references

Ten generated character concepts contributed from Pirate Island for shared illustration, costume and modeling reference. These are 2D PNGs, not models or rigs. The source style input is included and identified by SHA-256. All ten concepts await user selection; none is a shared runtime asset.

The authoritative export metadata is [pack.json](pack.json), discoverable through the existing library resource-pack ledger. It records each output's creation ID, exact prompt snapshot, dimensions, source hash, parent relationship and review state. Prompt snapshots preserve the original record byte for byte; paths written inside those historical records refer to the source project. Use pack metadata for the corresponding shared-library paths.
