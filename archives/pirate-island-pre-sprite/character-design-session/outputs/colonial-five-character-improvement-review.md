# Colonial women — individual character improvement pass

Five new review candidates, generated with the built-in image tool from the prior individual illustrations. Approved Beatrix identity art remains intact.

The prior pass overlooked repetition across the cast: similar pinned hair, ivory torsos, dark brown rendering, stern expressions and repeated gun gestures. Several claimed action relationships were not actually visible in the pictures. This pass prioritizes distinct expressions, readable physical actions, reduced clutter and clearer facial light. Changes concern illustration and staging, not faction balance or kit rules.

## Review limits

The cast now has a broader emotional range: Beatrix's fierce delight, Odette's concentration, Marisol's audacity, Clara's reassurance and Rosamund's satisfied command. Clara and Marisol show the largest character gains. The pictures remain closer to detailed cinematic illustration than boldly inked graphic novels. Exact height cannot be established from separate perspective images and remains a character-sheet requirement. Beatrix's grenade landing is outside the portrait; it is not a map of the whole assault. These images are not validated engineering or medical references.

All source versions are retained. The principal character-design document links the current candidates. Nothing was published. The current Git remote points to the donation app, so the game assets were not committed to that unrelated repository.
