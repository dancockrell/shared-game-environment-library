# Retained colonial character variants

Recorded 5 September 2026 following the instruction: “keep all the last ten as variants.”

All ten most recent generated files remain at their original paths. This is a frozen retention set, ordered by the verified local file timestamps at the time of the request; subsequent art will not change membership. The five portraits presented immediately before the latest improvement pass are also retained, so both interpretations of “last ten” are covered. Two overlap with the literal latest ten, making **13 distinct retained variants**, plus Beatrix’s existing approved version 10 identity reference.

Retention preserves options. It does not automatically select these images for the game or certify their anatomy, crop, continuity, animation suitability, or readiness to ship. Earlier criticism remains useful context in the individual prompt records and character review documents. No files were moved, replaced, or deleted.

The retained collection in the [canonical character-art manifest](<C:/Users/Admin/Documents/Codex/2026-09-04/pirate-island-work/outputs/assets/characters/character-art-manifest.json>) records each original file’s SHA-256, byte count, PNG dimensions, parent image, prompt record, retention groups, and separate production-admission state. Exact prompt records and summarized revision contracts are identified separately. Vendor model/version and terms metadata were not available in these records and are left unknown.

## Preservation check

Run `node outputs/variant-preservation-check.mjs` from the project directory. It verifies file hashes, byte counts, PNG signatures and dimensions, all parent and prompt paths, exact latest-ten membership, and the unchanged Beatrix identity copy. It reads files only and never admits an asset to the game. Verification is of preservation and recorded links; it is not a new visual review.
