# 2D asset intake

Owner direction, 8 September 2026: all projects use 2D artwork only. Do not acquire, generate, admit, restore or reuse 3D models, rigs, model builders, volumetric scenery or model-only material packs. The owner requested permanent deletion, including shared packs and archived copies.

1. Search the shared catalog for reusable 2D inputs.
2. Record original source, license or generation terms, creation ID, exact prompt and parent hashes. Generated images are never assumed CC0.
3. Inspect actual pixels at gameplay scale for style, perspective, silhouette and transparency.
4. Validate every animation frame in sequence: dimensions, duration, pivot, equipment continuity, mask edges and loop seams.
5. Record project approval separately from shared reference availability.
6. Publish only reproducible packs with source ancestry, output hashes and explicit review state.

Legacy source and material catalogs are historical records, not acquisition instructions. Their 3D payloads are prohibited and pending removal.
