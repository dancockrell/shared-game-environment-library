#### What changes in our implementation

1. Keep the existing character editor, identity/wardrobe contract, licensed body topology and Godot/Unity delivery path. Replace the failed fitting responsibility, not the whole application.
2. Construct a measured, shaped bodice pattern through the established pattern library. Explicitly convert its centimetre-based examples into the builder's metres. Darts, seams, shoulder slope, neckline and pointed hem are structural decisions; decorative channels cannot compensate for a wrong cut.
3. Preserve each panel's material coordinates, rest geometry and stitch identities. Newton's `add_cloth_mesh` derives rest elements from the supplied mesh: do not give it an already distorted drape and silently redefine that distortion as the rest shape. Its source assigns one third of each triangle's area times areal density to each incident vertex; our old unit-mass-per-vertex shortcut must not control the production garment.
4. Establish feasible placement and seam exclusions, then test contact during pose changes. Use explicit Godot Y-up to solver-coordinate conversion and back. Evaluate closures, armholes and belt/accessory contact, not just torso vertices. Do not claim Newton's implementation is mathematically identical to every OGC equation: inspect margins, truncation thresholds and contact filters in the pinned source.
5. Fit the existing approved character, not a generic mannequin as the finished deliverable. Compare silhouette, face, hair, cut and materials at the reference camera; inspect the back and movement separately. A paper benchmark, collision count or attractive reference displayed in a viewport is not generated character art.

### Original sewing kernel: construction baseline, not finished clothes

`tools/sewing-pattern.gd` compiles a schema-version-1 pattern with metre units. Each named panel has a simple polygonal `boundary` in fabric coordinates, an `origin`, and orthonormal `u`/`v` placement axes. Stitches reference `[panelId, boundaryEdgeIndex]` pairs and an explicit direction reversal. Shared-midpoint refinement preserves named boundary chains and vertex-to-fabric correspondence. Collinear redundant corners must be simplified first. Curved cuts, nonuniform seam sampling and gathers remain unimplemented.

The distance solve uses XPBD accumulated multipliers, inverse masses, compliance and a timestep parameter. Multipliers persist across iterations of one solve. The `simulate` entry point predicts positions with fixed-step damped gravity, calls this same constraint owner, then updates velocities from corrected positions. Optional flat-rest curvature constraints use four-vertex linear-precision stencils across interior panel edges; their weights sum to zero and annihilate the original flat panel. Their vector constraint preserves translation/rotation invariance and resists folding. This is a construction bending model, not a calibrated fabric plate model or a reproduced VBD/AVBD implementation. No bend stencil is yet constructed across a sewn panel boundary. Default inverse masses are per-vertex fixture values, not area/density-derived textile mass. The original cut/placement is not mutated.

The mesh builder retains one surface per panel, separate UVs across seams, clockwise render triangles, smooth normals and tangents. One UV unit is one metre of fabric, not a per-panel normalization. Both the solved mesh and editable pattern are retained by the test; source garment fixtures are not silently replaced with this coupon.

The test joins two 300 × 400 mm rectangles initially separated by 100 mm. At two refinement levels it has 50 vertices and 64 triangles. It checks fabric area, seam closure below 0.1 mm, edge-length error below 0.1%, deterministic solve, pinned vertices, an independent compliant two-point closed-form solution, concave/reversed boundaries, invalid input rejection, metric UV preservation and saved-mesh reload. These thresholds test construction machinery, not art admission. Body penetration and self-intersection measurements remain explicitly null.

### Triangle contact and complete fitting bodies

`tools/cloth-contact.gd` builds a deterministic median-split AABB hierarchy over the actual static triangles. Nearest-point queries handle triangle face, edge and vertex regions and are checked against exhaustive triangle distances. Outward-facing vertex sweeps catch front-to-back surface crossings; local surface-shell projection maintains a configurable separation (3 mm in the fixture). This is not a closed-solid classifier, a signed-distance field, moving-body contact, cloth edge/triangle continuous collision detection or self-contact. Open boundaries, source winding, creases and overlapping anatomy remain explicit limitations. Deep initial intersections outside the local contact band are not automatically repaired.

The source compiler now writes `female-fitting-surface.res` and `male-fitting-surface.res` through the existing source fitting function and hashes them in the build receipt. These contain the **complete unmasked body**, including existing body/face blend shapes, in common source space. Display-body variants intentionally remove geometry covered by source clothes and cannot serve as complete tailoring collision bodies. Fitting surfaces stay offline and are not added to the runtime character or selectable wardrobe. Current contact tests use their base shape, not a posed or morphed body.

The same compiler now emits `*-fitting-surface.json` for external offline garment solvers. It serializes the complete base mesh in metres/Y-up, reverses Godot's clockwise triangle winding to mathematical counterclockwise winding, and records the original `.res` hash and compiler hash. No morphology or placement is recomputed. Existing complete `.res` files can be serialized without rebuilding outfits/textures using `--export-fitting-surface <absolute-input.res> <new-absolute-output.json>` after the Godot user-argument separator. This mode refuses to overwrite an output. Normal source builds now include the JSON outputs in their receipt; the existing shipped GLBs were **not** rebuilt in this checkpoint.
