# Cross-project 2D production strategy

Owner direction, 8 September 2026: all projects use 2D artwork only. Do not acquire, generate, admit, restore or reuse 3D models, rigs, model builders, volumetric scenery or model-only material packs. The owner requested permanent deletion, including shared packs and archived copies.

Search shared 2D assets before authoring. Reuse flat character bodies, costumes, palettes, environmental motifs and animation conventions across projects while respecting each project's identity and ownership. Match the approved game reference before expanding a sheet. Rich distinct poses and smooth, correctly ordered animation are the goal; frame quantity is not a substitute for coherent motion.

For Olympus, use the built-in image generator authorized by the owner. Do not use paid model-generation APIs or external paid generation. Generate transparent outputs or deliberately controlled chroma backgrounds; do not remove a light background from pale character details. Preserve source images and record crops, pivots, timings, masks and parent hashes.

Previous body-rig, material-map, model source package and workshop guidance is superseded. Shared 3D removal remains pending after automatic approval review rejected deletion. See the pending inventory for actual disk state.
